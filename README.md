# Background
I've worked to create a project which tackles Coastal Wildlife Conservation efforts in the hopes to predict what areas are most at risk. I'm using data from areal images taken over the years by the Water Institute and heat map records of land change from the Costal Protection &amp; Restoration Authority.

#Currently
This is repo has a prototype with Streamlit (based off my Figma designs)
Actual data for predictions is shown in a CLI.
